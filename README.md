## About me

I'm Babiker, a software engineer with experience across **Laravel, Vue.js, and .NET Core**. I work across the full delivery cycle: understanding the problem, designing the system, building the interface and API, testing the workflows, and supporting the application in production.

At the **University of Tabuk**, my work includes **LearnFlow, Communities, Catalog, e-Magazine, and the Athar Moodle LMS**—connecting learning analytics, academic collaboration, curriculum information, and digital publishing.

My strongest work sits where business rules, data, and user experience meet: permission models, learning-outcome calculations, multi-vendor order flows, and interfaces that make complex information understandable.

## How I work
